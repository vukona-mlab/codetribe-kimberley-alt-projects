# Title: CSS Grid Mini Challenge

## Objective
A simple project to get you comfortable with CSS Grid and media queries.

## Requirements
Use the attached mobile and desktop view of the challenge to implement a responsive web page using CSS Grid and media queries. The web page should be viewable on devices as small as 480px and devices as large as 2160px. The task assesses your understanding of CSS Grid so no flexbox is expected. You are to use sprints for the task, using the guide below

### Sprints
1. Sprint 1: Add HTML (all your HTML tags)
2. Sprint 2: Introduce CSS for mobile views
3. Sprint 3: Introduce media queries to handle larger screens

### Branches
1. main - Holds the instruction.md, and design files. Waiting for PR.
2. dev - For the overall project changes before final submission, i.e. all branches are pushed to GitHub and then merged into the dev branch. 
3. layout/structure -  For sprint 1
4. layout/mobile - For Sprint 2
5. layout/desktop - For Sprint 3

Do not use uppercases in your branches.
